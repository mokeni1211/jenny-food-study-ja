# 「食品画像の知覚に関する調査」参加同意説明（Qualtrics版）

**実験実施責任者：** 名古屋大学大学院情報学研究科 准教授 孟 憲巍  
**正式承認研究題目：** 【要入力：倫理審査で承認された正式題目】  
**倫理審査承認番号：** 【要入力：承認番号】

本調査は、食品画像を見たときの知覚や判断について調べることを目的としています。対象は18歳以上の日本人成人です。所要時間は約10分です。

参加は自由です。参加しない場合や途中で中止した場合にも、不利益はありません。調査中に不快に感じた場合や体調が悪くなった場合は、いつでも画面を閉じて中止できます。

回答には、課題成績、反応時間、食品に関する回答、直近の食事、身長（cm）、体重（kg）が含まれます。氏名、メールアドレスなどは調査画面では尋ねません。

回答データは名古屋大学が契約・管理するQualtricsに送信・保存され、研究担当者および承認された共同研究者が学術・教育目的に限って利用します。**【要確認：Qualtricsにおける保存地域、保存期間、バックアップ方針をここへ記載】**。研究データは研究計画に従い10年間保存します。研究成果は国内外の学会や学術雑誌等で公表されることがありますが、公表時に個人が特定される情報を掲載することはありません。

調査完了時に、参加者ごとに固有のQualtrics Response IDを完了コードとして表示します。参加者には、報酬確認のため、このコードをCrowdWorks上で提出していただきます。研究者は、CrowdWorksに提出された完了コードとQualtricsの回答データを照合できるため、CrowdWorks上の参加者と調査回答を対応づけられる場合があります。この情報は、参加確認、報酬支払い、重複参加の確認、同意撤回への対応および研究上必要なデータ管理以外の目的には利用しません。

**同意撤回：** 【要確定：撤回可能期限と連絡方法】までに、CrowdWorksを通じて完了コードを添えてご連絡いただいた場合、対応する回答を特定して削除します。対応情報の削除後、データの匿名化・統合後、または研究成果の公表後など、回答を特定できなくなった後は撤回できません。

以上を理解し、18歳以上で、調査への参加に同意する場合は「同意します」を選択してください。同意しない場合は「同意しません」を選択するか、画面を閉じてください。
