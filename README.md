# Japanese Food Perception Study — Qualtrics package

This repository contains the static stimuli and Qualtrics integration files for a Japanese adult replication of Study 1.

## Qualtrics setup

Follow the Japanese instructions in [`docs/README_SETUP_JA.md`](docs/README_SETUP_JA.md).

The public stimulus base URL is:

```text
https://mokeni1211.github.io/jenny-food-study-ja/static
```

Example stimulus:

```text
https://mokeni1211.github.io/jenny-food-study-ja/static/img/cb_1.jpeg
```

Participant response data are not sent to GitHub. The repository only serves public experiment assets and contains setup materials. Responses are stored in Qualtrics.

## Release status

This package is not approved for production launch until the ethics approval number, formal approved title, Qualtrics storage/IP policy, and withdrawal deadline have been finalized.

No open-source or reuse license is granted for the supplied study stimuli.
